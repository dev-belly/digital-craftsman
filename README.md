# 数字工匠成长学习小屋 · 微信小程序

以「个人身份二维码」为入口的大学生能力档案系统。扫码即可查看技能档案、企业评价、作品集、人才指数,数据哈希存证可追溯。

> 产品设计详见 [项目设计文档.md](./项目设计文档.md)
>
> 准备提审时请按 [上线操作清单.md](./上线操作清单.md) 逐项完成。

## 运行步骤

### 1. 准备
- 安装 **微信开发者工具**(稳定版)
- 有 **已开通云开发的真实小程序 AppID**（非测试号）

### 2. 导入项目
1. 微信开发者工具 → 导入项目 → 选择 `digital-craftsman` 目录
2. 填入你的 AppID

### 3. 关联云环境
左侧文件树 → `cloudfunctions` → 右键 → **选择云环境** → 选你的环境

### 4. 修改环境 ID
将 [miniprogram/app.js](./miniprogram/app.js) 中两处 `env` 和 `envId` 改为你的云环境 ID

### 5. 部署云函数
对 `cloudfunctions/` 下的业务函数依次右键 → 「上传并部署：云端安装依赖」：
`register` → `login` → `recoverAccount` → `logout` → `changePassword` → `changeEnterprisePassword` → `getArchive` → `submitEvaluation` → `issueCertification` → `addWork` → `genWxaCode` → `listTalents` → `sendInvitation` → `respondInvitation` → `postJob` → `applyJob` → `manageJobApplication` → `initDB` → `updateProfile`。

`cleanupStages` 是旧数据迁移工具，不需要日常调用。

### 6. 初始化演示数据
1. 右键 `initDB` → 「云端测试」
2. 请求参数填: `{ "seed": true }` → 运行
3. 会创建或更新三份不同阶段的演示档案：王芳（作品阶段）、李明（企业好评阶段）、陈浩（已进入人才池）；重复执行不会新增重复演示数据

### 7. 配置数据库权限
参考 [数据库安全规则.md](./数据库安全规则.md)，将客户端数据库读写权限关闭。档案读取和修改均由云函数完成。

### 8. 预览
点「编译」后可直接选择学生端或企业端。已有账号可登录；新用户点击“立即注册”，填写资料并勾选用户协议与隐私政策。

学生自主注册成功后会立即把账号、档案写入云数据库并进入个人档案；内部体验期间，企业自主注册也会保存到云端并立即开通。内部测试账号见 [测试账号说明.md](./测试账号说明.md)。

## 企业端小程序工作台

企业在登录页切换到“企业端”，用公司 ID 和密码进入企业工作台，可以查看人才池、扫码查看学生档案、提交评价、发送面试/实习邀约、发布岗位。提交评价后自动:
**SHA256 证据哈希 → HMAC 数字签名 → 存证记录 → 人才指数重算**

`enterprise-web/` 里的 H5 页面仍保留为早期演示素材；当前推荐使用小程序内企业端。

## 关键设计说明

- **小程序码只携带 uid**：扫码后实时聚合档案，保证内容动态更新
- **一微信一账号**：学生与企业共用全局唯一绑定；首次成功注册或登录后，账号和当前微信双向绑定，不能被其他微信覆盖
- **密码安全**：自主注册密码和后续新密码采用 PBKDF2 加盐哈希；历史测试账号保持兼容并会在改密时升级，云端不保存明文密码
- **账号找回**：仅允许当前微信找回与其双向一致绑定的账号；客户端不能指定账号或 OpenID，换微信后需管理员人工核验
- **登录会话七天有效**：首页、作品、评价和资料修改均在云端校验账号对应的 uid
- **官方小程序码**：开发版只能由项目成员扫码；上线后生成正式版小程序码，普通微信用户才可进入
- **企业端小程序账号登录**：当前内部体验阶段注册后自动激活；历史 `pending` 账号在密码验证通过后也会自动激活。正式对外运营前需关闭测试自动开通开关并接入管理员审核
- **存证初期为 SHA256 哈希证据**：可用于完整性校验，但不能等同于真实区块链上链
- **隐私政策**：登录前需主动勾选，登录后也可在“我的”页面再次查看
