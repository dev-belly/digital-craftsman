# 会话过期时间契约

学生和企业的受保护云函数只接受尚未到期的会话。`expiresAt` 可以是云 SDK
返回的 `Date`、毫秒时间戳、可解析的日期字符串，或历史导出中的
`{ "$date": "..." }` 形式。

过期时间缺失、无法解析、不是有限时间值，或等于/早于当前时间时，都按登录
失效处理，返回 `code: 401`。无效日期不能因为 JavaScript 的 NaN 比较结果
而绕过过期检查。账号状态、密码版本、微信身份和会话归属仍须逐项核验。

每个云函数独立部署，因此各自保留相同的时间解析边界，不依赖部署目录外的
公共模块。`npm test` 中的 `scripts/testSessionExpiry.js` 用离线 SDK 调用
14 个实际入口，覆盖无效/到期时间和四种有效历史格式；测试不接触真实云环境。
